# Memory — ShopNow (shared)

Short durable facts for both packages. Client: [MEMORY](./client/MEMORY.md) · Server: [MEMORY](./server/MEMORY.md).

## Decisions

- The app moved from Supabase to Express + Prisma + Neon (commit `52176dc`, then docs in `a9b76be`). The Express API is the only data path in use; leftover Supabase code remains in the client (see [client TASKS](./client/TASKS.md)).
- `client/` and `server/` were once git submodules and are now tracked as one repo (`6c67ae6`). There is no root `package.json` or workspace.
- Brand copy lives in one JSON file at the repo root; theme tokens stay in CSS by choice. The manifest is imported straight into the client, so editing it needs a rebuild.
- Guest cart and wishlist live in Redux Persist (`localStorage`) and are pushed to the API after login.
- Both packages keep `package-lock.json` and `bun.lock`; scripts in the docs use npm.
- The JWT is sent as an HttpOnly cookie, and signup and login responses also include it in the JSON body. The server accepts a `Bearer` header as well as the cookie.
- Social sharing: `client/public/brand/share-card.jpg` is generated by `npm run share-card` in `client/`; metadata is in `client/src/lib/seo.ts`. See [client ARCHITECTURE](./client/ARCHITECTURE.md).
